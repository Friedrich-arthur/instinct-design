# 供应商对比表：页面与状态交付方案

首屏改为：**“3 家报价已读入，B 运费待核对。”** 下方直接说明：**“可以比较单价、起订量和交期；完整成本对比还缺 B 运费及相同报价口径。”** 主操作为 **“核对 B 运费”**，打开 B 的运费证据侧栏。删除旧文案“同步全部完成，可以采购”。

保留现有品牌、表格密度、七列顺序与键盘操作。供应商选中只表示加入比较，不代表确定供应商或采购；页面不提供购买、下单或发邮件动作。

## 1. 首屏交给设计师的排布

从上到下：现有页头 → 一条结果与待办提示 → 表格工具栏 → 现有高密度表格。不要增加大卡片、欢迎区或占据首屏的解释面板。

**结果提示**

> 3 家报价已读入，B 运费待核对。 〔核对 B 运费〕
>
> 可以比较单价、起订量和交期；完整成本对比还缺 B 运费及相同报价口径。

“报价口径”指采购数量、实际币种、运费适用的目的地与数量、税费是否包含；本题未提供这些信息，因此不推断它们一致。产品已有已核对的值时直接显示，避免重复要求用户确认。

**工具栏**

左侧保留原有表格控件（已有筛选、排序时原样保留）；右侧显示“已选 n 家”与〔比较已选〕。至少选 2 家才可进入比较，少于 2 家时旁边可见“选择至少 2 家进行比较”。不默认勾选最低单价。

**表格首屏示意**

| 供应商 | 单价 | 起订量 | 交期 | 运费 | 证据更新时间 | 选中 |
| --- | ---: | ---: | ---: | --- | --- | :---: |
| A　查看更多 | $9 | 500 | 25 天 | $700 | 今天 | □ |
| B　查看更多 | $8.6 | 600 | 20 天 | **待核对** · 核对<br>运费读取失败 | 昨天 | □ |
| C　查看更多 | $9.2 | 400 | 23 天 | $650 | 今天 | □ |

B 的“待核对”不能显示为 $0、空白或“供应商未报价”：已知原因是字段解析失败，尚不能判断原文件有没有运费。原文件与旧表格行继续保留。

数值右对齐并沿用等宽数字，单位清晰；异常单元格使用品牌现有警示色、文字与图标，不整行染色。A、C 不因 B 失败显示失败状态。保持原有紧凑行高，B 的说明允许局部两行；宽度不足时横向滚动，固定表头与供应商列，七列不藏到侧栏。焦点框、行悬停与勾选样式沿用现有系统，不新增品牌色。

## 2. 比较视图：先看差异，再判断能否同口径比较

点击〔比较已选〕后，仍用同一张表展示所选供应商，列、行数据和键盘规则不变。上方标题为“比较已选 n 家”，提供〔返回全部报价〕；保留原筛选、排序、勾选和滚动位置，返回时恢复。

若选中 A、B、C，在表格上方放一条紧凑摘要：

> B 的单价数值最低、交期最短，但运费待核对；C 的起订量最低。完整成本尚不能直接比较。

“最低”“最短”只针对已选候选的当前原始字段，并列时标明并列；实际币种一致前，单价只描述表内数值，不判定哪家价格更便宜。取消勾选或数据更新后摘要随之更新。不要加“推荐采购”、综合评分、优胜者徽章或默认排名。

比较分为两个可见状态：

| 状态 | 界面表现 | 用户可以做什么 |
| --- | --- | --- |
| 原始字段可比较，完整成本待补全 | B 运费状态留在表内；上方可见“完整成本待补全”，列出 B 运费和未核对口径 | 继续比较单价、起订量、交期；打开缺失项核对 |
| 相同口径已核对 | 上方显示本次比较数量、币种和运费范围；仅在报价确实适用于该口径时展示含运费金额 | 比较该口径下的金额，查看计算与依据 |

可以在“比较口径与计算”展开区显示按各自起订量代入的算式：A 为 $9 × 500 + $700 = $5,200；C 为 $9.2 × 400 + $650 = $4,330；B 为 $8.6 × 600 = $5,160，**另加待核对运费**。标签必须是“待核对算式：按各自起订量代入，运费适用范围未确认”，不能称为最终到岸价或用于完整成本排名。这些数量不同，单价与运费是否适用、币种及税费口径未核对，不据此断言 C 更便宜。

若后续提供统一数量，小于某家起订量时该家显示“未达到起订量”；数量达标也不自动证明单价或运费适用。完整成本必须使用已核对的适用报价，不把三家的现有数字直接乘成共同订单金额。

## 3. 侧栏：看证据、核对字段，并返回原行

“查看更多”继续打开现有侧栏。标题为“A / B / C · 报价详情”，保持来源行高亮；点击 B 单元格“核对”或页头“核对 B 运费”时，同一侧栏直接定位到运费字段。

侧栏按以下顺序展示：

1. 当前结果：B 显示“报价已读入，运费读取失败；当前运费尚未核对”。
2. 报价证据：原文件查看入口、对应页或字段位置（有定位信息时显示）、原始文字、证据更新时间。原文缺失时写“暂无可定位的运费原文”，不伪造摘录。
3. 恢复动作：〔重新读取运费〕只重试 B 的这一字段；人工核对入口提供金额、实际币种、适用数量／目的地与来源说明。沿用既有报价字段模型，用户未掌握的值保持未核对。
4. 次级展开“读取详情”：提供失败原因、最近尝试时间。技术错误码放这里，不替代首屏恢复提示。

人工填写后用〔保存核对〕明确写入本对比表。只有存储成功才显示“核对结果已保存到本对比表”，保留原文件、原始解析结果与人工修订来源。保存后不自动选择 B、采购或发邮件。

侧栏关闭时恢复打开前的同一行、同一触发控件与横纵滚动位置；勾选、排序、筛选不变。通过页头打开 B 时，关闭后焦点回到页头按钮。侧栏沿用原有模态或非模态行为，不改变表格键盘语义；模态侧栏维持 Tab 焦点边界，非模态侧栏允许键盘返回表格。Esc 与可见关闭按钮行为一致。

有未保存编辑时，关闭操作显示“保留草稿并关闭／继续核对”；草稿只在当前页面会话保留，重开同一字段恢复并标注“未保存”。刷新或离开前提示未保存内容；不把暂存草稿写成已持久保存。若侧栏打开期间该行因用户主动筛选而不可见，关闭后焦点回表格工具栏，并保留筛选，不擅自改筛选把行找回来。

## 4. 错误与恢复状态

| 触发／状态 | 首屏与运费单元格 | 恢复行为与保留内容 |
| --- | --- | --- |
| 本题当前状态 | “3 家报价已读入，B 运费待核对”；B 显示“待核对／运费读取失败” | 核对入口可用，原文件、旧行及 A、C 数据保留 |
| 正在重新读取 B 运费 | B 显示“正在读取运费”；其余已知字段仍可查看比较 | 本字段重试按钮暂时禁用；不清空整表、不重复插入 B、不阻断其他行 |
| 重试仍失败 | “B 运费仍未读取，原文件和已读入报价已保留” | 保留核对入口与人工填写内容；可再次尝试。失败信息留在字段内，不能仅靠短暂 toast |
| 本次读取失败但有历史运费 | 显示“上次值 $… · 日期，本次未核对” | 历史值不覆盖、不冒充本次报价；完整成本比较仍标记待核对 |
| 读取成功并保存成功 | B 展示实际金额；提示“B 运费已补全” | 若报价口径仍有未知，仍显示“完整成本口径待核对”；不跳成“可以采购” |
| 文件可读但未找到运费 | 显示“未找到运费，待核对” | 与解析失败分开，保留原文件供专家判断；未知不换算为零 |
| 人工保存失败 | 侧栏显示“核对结果未保存，请重试” | 保留草稿和旧值，焦点留在错误附近；不显示成功、不关闭侧栏 |
| 读取成功但保存失败 | “已读取到运费，尚未保存” | 候选结果留在侧栏供检查和重新保存；表格保留原状态，不把未存结果用于完整成本比较 |
| 原文件暂时打不开 | “原文件暂时无法查看，已读入字段仍保留” | 提供重新查看入口；不删除报价，不把文件不可用解释为供应商撤回 |

重试或人工修订成功后保持行顺序和键盘焦点；排序列受更新影响时显示“数据已更新，重新排序”，不继续显示该列已按最新值排序，由用户执行后再移动行。有人工草稿时，重新读取结果只作为候选显示，不覆盖草稿。证据更新时间沿用来源证据时间，“最近读取时间”和“人工核对时间”在详情中单独记录；重试发生在今天不能把 B 的昨天证据改成今天。

## 5. 简短设计理由

旧页头把读取完成错误地变成了采购结论。本方案把已完成的报价读取与未完成的运费核对放在同一首屏，专家不用展开侧栏就能看见影响比较的缺口。保留七列与键盘流程，侧栏只承载证据和恢复细节；不同起订量与未知运费始终可见，避免最低单价被误认成最低采购成本。

## 6. 可检查的行为与交付边界

本交付是设计方案，未实现界面、存储或解析，也未执行采购、邮件及其他外部操作。以下是交给设计与开发的验收行为，不能当作已通过的运行测试。

- **首屏理解：**只读页头和表格，能确认 3 家报价已读入、B 运费读取失败、完整成本仍待补全；不存在“可以采购”的完成态。
- **比较正确性：**选 A、B、C 后，B 单价显示数值最低和交期最短，C 起订量最低；B 的未知运费不等于零。不同起订量的算式不进入完整成本排名。
- **局部恢复：**重试 B 运费失败，A、C 与 B 已知字段、原文件、历史值和勾选仍在；连续点击不会产生重复行。成功但口径未知时仍保留口径提示。
- **键盘与回位：**既有表格快捷键不重新映射；勾选框可用原有键盘方式切换。用键盘打开 B 的“查看更多”，关闭后回到该控件，横纵滚动、选择与筛选不丢。焦点样式清楚，状态有文字，读屏能读到 B 运费异常。
- **保存与刷新：**人工保存失败后草稿仍在；成功提示必须等真实存储成功。保存成功后刷新，应恢复已存结果及其人工来源；未保存草稿不声称已持久化。
- **一致性与更新：**页头、单元格、比较摘要和侧栏引用同一状态；只读到一半时不出现一处成功、一处失败。一次字段重试只加载该字段，表格不全屏闪白、不跳回顶部。
- **窄窗口与性能：**缩窄窗口后通过横向滚动访问全部七列，供应商身份与 B 的异常仍可定位；大表沿用现有渲染和键盘机制，侧栏证据按打开时加载，不为每行预加载原文件。
- **授权与安全：**核对、勾选与比较只改变本对比表；不会产生订单、采购承诺或邮件。原文件访问沿用现有权限，不因错误恢复新增公开链接；保存修订可追溯到原值与来源。
