# Triage labels

| Role | Label | Meaning |
| --- | --- | --- |
| Specified agent work | ready-for-agent | Complete task definition; start once blockers are resolved |
| Human action | ready-for-human | Requires an actual publishing account or human action |
| Product improvement | enhancement | A scoped improvement to the Skill or its delivery |
| Content correction | documentation | A correction or improvement to public instructions |
| Reproducible defect | bug | Observed behavior fails the stated task or contract |

Labels describe routing, not proof of completion. Close work only after its actual acceptance criteria are met.
