# Visual craft

These are original defaults for applying this method. They are not a reconstruction of Instinct's brand system. Preserve the product's existing identity and component library when available.

## Give the result visual priority

Use a clear reading order. Put the outcome or current state first, the consequence next, and the useful action near the relevant content. Make expanded evidence quieter without making it unreadable.

Establish hierarchy with spacing, type size, weight, and grouping before adding decoration. Reserve the strongest emphasis for the current result or action. Avoid a page where every panel looks equally urgent.

## A restrained starting palette

For a new neutral interface, start with a warm or cool light background, high-contrast text, subtle borders, and one accent color. Use color to identify action and meaningful status. Pair status color with words or icons so color is not the only signal.

Dark mode is an equally valid product choice. Choose it for the audience and context, not because an AI product is expected to look futuristic. Gradients, illustrations, and motion need a role in comprehension or brand expression.

## Readable, consistent controls

Use the existing type family. For a new web prototype, a system font keeps loading and maintenance small. Start with comfortable body text and line spacing, then check long labels, multilingual content, and small screens.

Use a consistent spacing scale and control style. Keep touch targets comfortable, focus visible, and links identifiable. Name controls by their consequence. A collapsed view should still look actionable.

Preserve semantic HTML or the platform's equivalent. Check text contrast, keyboard operation, focus order, screen-reader labels, zoom, and narrow layouts against the product's applicable accessibility requirements. Visual inspection alone does not establish compliance.

## Motion and states

Use brief transitions to show a change of state or location. Respect reduced-motion settings. Avoid animation that delays an action or distracts during waiting.

Design empty, loading, waiting, success, partial-success, and failure states that are relevant to the actual workflow. Use the same words and visual hierarchy in every state. A beautiful successful state cannot compensate for an unclear failure state.

## What to remove

Remove panels that don't help the current job, redundant metrics, repeated badges, technical process narration, and decorative cards around short text. Keep an element when removing it would harm comprehension, access, control, or brand meaning.

Document any concrete color, spacing, font, or motion value as a chosen implementation default. Do not attribute that value to Instinct without an inspected source that supports it.
